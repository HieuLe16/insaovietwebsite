# Website In Sao Việt

Website tĩnh của Công ty Cổ phần In Sao Việt (insaoviet.com).

- `index.html`: bản tiếng Việt (trang chủ)
- `en/index.html`: bản tiếng Anh
- `img/`: ảnh dùng trên trang
- `CNAME`: tên miền cho GitHub Pages

Form báo giá mở ứng dụng email của khách với nội dung đã điền sẵn, gửi tới insaoviet2006@gmail.com.
Ảnh đầu trang, ảnh máy móc và ảnh kho giấy là ảnh mẫu từ Unsplash, sẽ thay bằng ảnh thật của xưởng.
